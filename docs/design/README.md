## WALL-E Drive — Design Bundle

This folder contains the design-system source for the WALL-E Mini phone teleoperation UI: a standalone `SPEC.html` design brief and one self-contained HTML preview card per component, each tagged with a `<!-- @dsCard group="..." -->` marker so they can be pushed to a [claude.ai/design](https://claude.ai/design) project via the **DesignSync** tool (`/design sync` in Claude Code), which uploads every `@dsCard`-tagged file as a card in the named group. The live source of truth that any restyle must ultimately be ported back into is the `_DRIVE_HTML` inline string in [`pi_app/web/teleop.py`](../pi_app/web/teleop.py) — that string is served verbatim by a Flask Blueprint with no build step, so all CSS and JS must remain inline and dependency-free.
